## 1. 论文要复现什么（方法拆解，全部出自论文文本层）

**方法一句话**：k+1 张图（k=10 个 NetVLAD 检索的带位姿参考 + 1 查询）一起进 VGGT 式交替注意力 transformer（L=24、1.1B、DINOv2 patch-14、VGGT 权重初始化）。参考位姿 SE(3) 展平 R¹² → 小 MLP → 相机 token y；与可学习 token l 相加 g=l+y（**所有帧都有 l**，查询 yq=0，附录 A.1 证明全可学习配置对训练稳定性必要）；**每层 frame attention 后重注入** gn=go+y；4 层自注意力 camera head + 线性层输出 [q, c, fx, fy]。位姿按参考相机中心均距 s=mean‖ci‖ 归一化，推理时乘回 s、复合第一个参考位姿得米制绝对位姿，无需几何优化（§3.1–3.2）。训练：4×H200、1M iter、AdamW 1e-5→1e-8、最长边 518px、宽高比 0.33–1 随机、8 数据集（Co3D/DL3DV/VKITTI2/BlendedMVS/Re10K/MegaDepth/ARKitScenes/ScanNet++）、平移/旋转/焦距三项 homoscedastic 不确定性加权损失（§3.3 式 1–2，可学习 sc/sq/sf）。

**复现目标数字清单**（按可对照性排序）：

## 5. 复现方案（三 Stage，套 ScientistTwo 纪律）

### Stage A — 评测管线 + ReLoc3r 基线复现（≈1 天 + 下载等待）

对应论文：Table 2 ReLoc3r 行 + Table 1 MegaDepth-1500 ReLoc3r Pair 行。

1. 下载 Cambridge（34.1GB，gdown 断点续传）→ 先 `unzip -l` 看结构 → 解压到 `reloc3r/data/cambridge` → 完整性清单（5 场景目录、`dataset_train/test.txt`、pose 文件计数，对照 `cambridge_retrieval.py` 的 stat_Cambridge 帧数表）→ **清单 + sha256 固化进 `eval/manifest.sha256`**（I2 协议不可变的起点）。
2. 跑 `scripts/eval_cambridge.sh`（NetVLAD top-10 → ReLoc3r 相对位姿 → motion averaging 绝对位姿），逐场景输出固定 schema 的 `metrics.json`。
3. 判据：Cambridge 逐场景中位数误差与 Table 2 ReLoc3r 行同数量级、**avg 相对差 ≤20%**（论文未报 seed/检索缓存细节，不承诺 bit-exact）；MegaDepth-1500 用现成脚本回归（已有 49.59 基线，成本约 2 分钟）。
4. **I1 纪律**：干净目录重跑一次，数字一致才算过。

产物：`evidence/stageA_reloc3r.json` + 与论文表格逐行并排对照表（数字全部从台账生成，不由 LLM 转写）。

### Stage B — Table 4 "Frozen (no pose)" 行复现（≈1–2 天，纯推理）

对应论文：Table 4 frozen 行（Cambridge 41.0 cm/0.374°）+ Table 5 前两行 + Figure 5 的 k 曲线结构。

1. hf-mirror 下载 `facebook/VGGT-1B`（只取 safetensors，省 5GB）；clone `facebookresearch/vggt`（参考 `map-anything` 一并 clone，Apache-2.0）。
2. **廉价前置锚点**：先在本机已有的 MegaDepth-1500 上跑 VGGT Pair 推理，对照 Table 1 VGGT Pair 行（40.93/60.81/76.61，容差 ±15%）——验证权重下载、camera head 用法、AUC 口径全部正确，再上 Cambridge。
3. 按附录 B.1：VGGT aggregator + 自带 camera head 对 (10+1) 图前向 → 相对位姿 → **motion averaging** 解全局位姿与尺度；另跑 Umeyama 7-DoF 对齐对照。**数据加载、检索缓存、误差函数全部复用 Stage A 的，只换预测器**——保证同一协议下可比。注意分辨率口径：VGGT/MultiLoc 用最长边 518px（附录 C），与 ReLoc3r 的 512/384 不同，协议文件里分别固化。
4. 判据：Cambridge avg ≈ 41.0 cm / 0.374°（±15%）；Umeyama vs motion avg 次序与 Table 5 一致（motion avg 旋转更接近）。**这一行过了，说明"检索→多视角前向→尺度恢复→误差统计"整条论文评测协议已在本机还原，Stage C 的任何增益才可信。**
5. 顺带产出 Figure 5 结构：k∈{1,2,4,10,20} 重跑 frozen 变体（k=1 应出现尺度歧义大误差，与论文 24 m 定性一致），画精度-延迟曲线（数值不承诺对上论文，论文该曲线是 trained 模型 + H100）。
6. 显存预案：11 帧×518px 单次前向若 OOM → 逐 query 处理 / 降分辨率，风险低于 Stage C。

### Stage C — MultiLoc-lite：核心机制归因验证（≈4–6 天，训练）

对应论文：贡献 1/2/3（位姿条件化多视角回归）+ Table 4 的 frozen→trained 方向性增益（Cambridge 41.0→29.5 cm，约 28%）。

**C0 显存冒烟硬门禁（先于一切训练投入）**：单场景单 query，11 帧×518px bf16 前向 + 反向（冻结主干、gradient checkpointing），测显存峰值。OOM → 降 448/392px 重测；仍 OOM → Stage C 降级为"仅推理消融"（用 frozen 变体做 k/检索消融），训练部分挂起等算力。**门禁不过不烧训练预算。**

不自研框架，只写论文相对 VGGT 新增的最小三件（新代码目标 <800 行，注入实现可参考 MapAnything 的位姿条件化方式）：

1. `PoseTokenMLP`：SE(3)→R¹² 展平 → MLP → d 维 y；可学习 l（**全图都有**，附录 A.1：仅查询有 l 会梯度尖峰）；g=l+y，查询 yq=0。
2. 每层注入：frame attention 后 gn=go+y（改 VGGT aggregator 交替注意力路径的残差入口，`vggt/layers/block.py` 级改动）。
3. 训练环：式 (1)(2) 不确定性损失（平移/旋转/焦距三项 + 可学习 sc/sq/sf）+ AdamW lr 1e-5 cosine 截短（1M iter 不现实，iter 数按冒烟结果定并写入台账）；**只训 MLP、l、camera head**；主干冻结、bf16、gradient checkpointing。是否加最后 4 block LoRA：默认不加，见 §8 决策点 4。

**数据与 subset-first**（ScientistTwo §3.2）：
- **冒烟（零下载）**：本机 7Scenes（已有 3.0GB，reloc3r `sevenscenes.py` 数据集类现成）单场景 × 2000 iter——验证三项 loss 均下降、"注入开/关"前向输出存在差异（证明 y 真的进了计算图）。7Scenes 不在论文训练集内，**仅作机制冒烟，偏差写 `docs/decisions/`**。
- **主训练（论文对齐）**：MegaDepth 子集，先 5 个场景（室外域，与 Cambridge 同域，迁移最合理），官方源按场景下载 + `preprocess_megadepth.py` + reloc3r 提供的 pairs 清单档案处理；采样/增强按论文 §3.3 "similar to VGGT"（518px、宽高比 0.33–1）。场景清单与下载体积立项时核实。

**评测**：Cambridge **零样本**（不训 Cambridge，保持论文范式），对照三个锚点：Stage B frozen（应显著优于）、Stage A ReLoc3r（应优于）、论文 MultiLoc 0.29/0.35（**预期达不到**，如实报差距与归因：冻结主干 + 截短训练 vs 全参 1M iter）。

**消融归因验收**（ScientistTwo §3.4，硬门禁）：去掉 y 注入（置零）后精度必须回落到 frozen 水平；位姿条件化组件的消融差值须占总增益主要部分（阈值 ≥50% 写进 task.yaml）——增益归因不到所提机制则判 Refuse，不得声称复现成功（TeCh 判例）。

产物：`evidence/stageC_lite.json`、`stageC_ablation_no_pose.json`、`code/lite/`（三个模块 + train.py）。
